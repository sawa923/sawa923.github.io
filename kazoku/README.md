# わが家ノート（家族専用ページ）

家事の分担と日々の記録を、家族だけで共有するページです。
公開先は `https://sawa923.github.io/kazoku/` です。

- **カテゴリ（家事など）**：月ごとの表（行が日付、列が項目）で、終わったらマスを押してチェックします。誰がやったかも残ります。タブの「＋」でカテゴリを追加でき、「項目を編集」で列の追加・削除・並べ替えやカテゴリ名の変更ができます。設定は Firestore の `chores/_settings` に保存されます。
- **記録**：日付を選んで、その日のできごとを書きます。消せるのは書いた本人だけです。

ページのプログラムは誰でも見られますが、**中身（家事や記録）は登録した家族しか読み書きできません**。
Google アカウントでログインし、Firebase のルールでメールアドレスを確認しているためです。

## 構成

- `index.html` / `style.css` / `app.js` … 画面と動き
- `config.js` … Firebase の接続設定（最初に一度だけ貼り付け）
- `firestore.rules` … 家族だけが読み書きできるようにするルール

## 更新するとき

`app.js` や `style.css` を変えたら、`index.html` の `?v=6` の数字を1つ増やします。ブラウザが古いファイルを使い続けるのを防ぐためです。

## はじめての準備（一度だけ）

費用はかかりません。Firebase は無料の「Spark プラン」のまま使います。途中で「アップグレード」や「Blaze プラン」を勧められても押さないでください。

### 1. Firebase のプロジェクトを作る

1. パソコンのブラウザで https://console.firebase.google.com を開き、自分の Google アカウントでログインします。
2. 「プロジェクトを作成」（または「Firebase プロジェクトを始める」）を押します。
3. プロジェクト名に `wagaya-note` など好きな名前を入れて「続行」。
4. 「Google アナリティクス」はオフにして「プロジェクトを作成」。できたら「続行」。

### 2. Google ログインを使えるようにする

1. 左のメニューで「構築」→「Authentication」を開き、「始める」を押します。
2. 「ログイン方法」タブで「Google」を選び、「有効にする」をオンにします。
3. 「プロジェクトのサポートメール」で自分のアドレスを選び、「保存」。
4. 同じ画面の「設定」タブ →「承認済みドメイン」→「ドメインを追加」で `sawa923.github.io` を入れて「追加」。

### 3. データの保存場所を作る

1. 左のメニューで「構築」→「Firestore Database」を開き、「データベースを作成」。
2. ロケーションは `asia-northeast1 (Tokyo)` を選んで次へ。
3. 「本番環境モードで開始」を選んで「作成」。
4. 上の「ルール」タブを開き、入っている文字を全部消して、このフォルダの `firestore.rules` の中身を貼り付け、「公開」を押します。

### 4. 家族を登録する

1. Firestore の「データ」タブで「コレクションを開始」を押します。
2. コレクション ID に `members` と入れて「次へ」。
3. 「ドキュメント ID」に家族の Gmail アドレスを**小文字で**入れます（例：`taro@gmail.com`）。
4. その下のフィールドに、名前 `name`、タイプ「string」、値に画面に出したい呼び名（例：`パパ`）を入れて「保存」。
5. 2人目からは `members` を選んで「ドキュメントを追加」で同じように登録します。家事の担当の選択肢にもこの呼び名が出ます。

家族を増やしたり外したりするときも、ここでドキュメントを追加・削除するだけです。

### 5. 接続設定を取り出す

1. 左上の「プロジェクトの概要」の横の歯車 →「プロジェクトの設定」を開きます。
2. 下の方の「マイアプリ」で `</>`（ウェブ）のアイコンを押します。
3. アプリのニックネームに `wagaya-note` などを入れて「アプリを登録」（「Firebase Hosting も設定する」はチェック不要）。
4. 表示される `const firebaseConfig = { ... };` の部分をコピーして、Claude のスレッドに貼り付けてください。`config.js` に入れて公開まで進めます。
   （この値はページに埋め込む前提のもので、見られても問題ありません。パスワードは不要です。）

## 使い方

1. `https://sawa923.github.io/kazoku/` を開き、「Google でログイン」を押します。
2. 登録したアドレスなら、家事と記録の画面が出ます。
3. 「このアカウントはまだ登録されていません」と出たら、表示されたアドレスを手順4で登録してください。

スマホのホーム画面に追加しておくと、アプリのように開けます。

一度ログインすると、ログアウトしない限りそのブラウザではログインしたままになります。毎回ログインを求められる場合は、シークレット（InPrivate）ウィンドウを使っていないか、「ブラウザを閉じるときに Cookie やサイトデータを削除する」設定がオンになっていないかを確認してください。
